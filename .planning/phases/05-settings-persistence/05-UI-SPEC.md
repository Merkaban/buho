# Phase 5 — UI Design Contract

> Visual and interaction contract for Settings & Persistence. Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (hand-built components with Tailwind CSS) |
| Icon library | none (inline SVG where needed) |
| Font | System stack: `-apple-system, BlinkMacSystemFont, "SF Pro Display", "Segoe UI", sans-serif` |

**Rationale:** Phase 5 extends the existing Stepper component pattern. No new libraries needed. The duration stepper reuses the exact same visual pattern as inhale/hold/exhale steppers.

**Phase 5 usage:**

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | None (session starts by tapping circle, existing behavior) |
| Duration label | "duration" (lowercase, matching "inhale"/"hold"/"exhale" pattern) |
| Duration unit suffix | "min" displayed after the value number |
| Duration zero state | "0" with "min" suffix (means infinite/no timer) |
| Countdown format | "M:SS" (e.g., "5:00", "0:32") -- no leading zero on minutes |
| Countdown zero | Not displayed (timer only shows when duration > 0) |
| Empty state heading | Not applicable (settings always have values) |
| Empty state body | Not applicable |
| Error state | Not applicable (localStorage failure is silent -- app uses defaults) |
| Destructive confirmation | Not applicable (no destructive actions in this phase) |

**Tone:** Minimal, calm. Single lowercase words for labels. Numbers use tabular-nums for alignment stability.

## Layout Contract

| Property | Value |
|----------|-------|
| Duration stepper position | Below existing inhale/hold/exhale row, vertically separated by 32px (`mt-8`) |
| Duration stepper alignment | Centered horizontally, same container as timing steppers |
| Countdown position | Centered horizontally, 24px below the breathing circle center |
| Countdown z-index | Above background, below any future overlays |
| Controls fade | All controls (timing + duration + music toggle) fade out on session start with `opacity-0 pointer-events-none transition-opacity duration-500` |

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Tap +/- on duration | Increments/decrements by 1 minute |
| Duration min | 0 (no timer, infinite session) |
| Duration max | 30 minutes |
| Duration at min (0) | Minus button disabled (opacity 0.3) |
| Duration at max (30) | Plus button disabled (opacity 0.3) |
| Session start | All controls fade out, countdown appears (if duration > 0) |
| Session auto-stop | When countdown reaches 0:00, trigger same stop flow as manual tap (dispatch STOP, stop animation, stop audio, release wake lock) |
| Session manual stop | Same as current behavior -- countdown disappears, controls fade back in |
| Countdown tick | Updates every second, counts down from `duration * 60` seconds |
| Settings persistence | On any value change, debounce 500ms then write all settings to localStorage |
| App startup | Read localStorage, apply persisted values to initialState before first render |

## Visual Details

### Duration Stepper
- Matches existing Stepper pattern exactly: label on top, +/- buttons flanking value
- Label: "duration" in `text-white/60 text-xs uppercase tracking-wider`
- Value display: number + "min" suffix, e.g., "5 min"
- Value font: `text-white text-lg tabular-nums`
- Suffix "min": same `text-white text-lg` but no tabular-nums needed
- +/- Buttons: `w-8 h-8 rounded-full border border-white/30 text-white flex items-center justify-center`
- Active state: `active:bg-white/10`
- Disabled state: `disabled:opacity-30`
- Width of value area: `w-12 text-center` (wider than timing values to accommodate "min" suffix)

### Countdown Display
- Text: `text-white/60 text-sm tabular-nums`
- Position: `absolute` below circle, `top-[calc(50%+80px)]` (circle center + circle radius at rest + gap)
- Alignment: `left-0 right-0 text-center`
- Fade: same `transition-opacity duration-500` pattern as controls
- No background, no border -- just floating text on sage green

### Persistence Behavior (invisible)
- localStorage key: `"mindfulone-settings"`
- Stored shape: `{ inhale: number, hold: number, exhale: number, duration: number, musicEnabled: boolean }`
- Read on mount: if key exists, parse JSON and use as initial state; if missing or corrupt, use DEFAULT_CONFIG
- Write on change: debounce 500ms after any config or music toggle change

## Accessibility Notes

| Concern | Approach |
|---------|----------|
| Duration stepper | +/- buttons have `aria-label="Decrease duration"` / `"Increase duration"` |
| Countdown | `aria-live="polite"` on countdown element so screen readers announce time changes (throttled to every 30s to avoid noise) |
| Countdown hidden | `aria-hidden="true"` when not visible |
| Controls hidden | `aria-hidden="true"` when faded out during session |
| Touch targets | +/- buttons are 32x32px (meets minimum 44px with surrounding padding from flex gap) |

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vercel CDN -> iOS Safari | HTTPS delivery of static PWA bundle |
| Service Worker -> Cache API | SW populates and reads from browser cache |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Cached assets | accept | HTTPS ensures integrity in transit. Workbox uses content hashes for cache keys. No sensitive data cached. |
| T-01-02 | Denial of Service | Cache storage quota | accept | PWA bundle is < 1MB. iOS provides at least 50MB cache quota for installed PWAs. |
</threat_model>

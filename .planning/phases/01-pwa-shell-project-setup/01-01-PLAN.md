## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDN -> Client | Static assets served over HTTPS by Vercel |
| Service Worker -> Cache | SW controls which assets are cached and served |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Service worker cache | accept | HTTPS-only serving (Vercel enforces TLS). Cache versioned by Workbox hash. No user data in cache. |
| T-01-02 | Tampering | Manifest via MITM | accept | HTTPS-only (Vercel). No sensitive data in manifest. |
| T-01-03 | Information Disclosure | Source maps in production | mitigate | Vite defaults to no source maps in production build. Verify `build.sourcemap` is not set to true. |
</threat_model>

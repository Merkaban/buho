# Phase 1 — UI Design Contract

> Visual and interaction contract for the PWA shell and navigation scaffold. Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none |
| Icon library | none (no icons in Phase 1) |
| Font | System stack: `-apple-system, BlinkMacSystemFont, "SF Pro Display", "Segoe UI", sans-serif` |

**Rationale:** This is a minimal meditation app with black backgrounds, a white circle, and text. No component library is needed. The system font stack gives native iOS feel with zero loading cost.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Dot indicator gaps, compact element spacing |
| md | 16px | Default element spacing, safe area minimum padding |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps between major elements |
| 2xl | 48px | Page-level vertical padding |
| 3xl | 64px | Not used in Phase 1 |

Exceptions: iOS safe area insets use `env(safe-area-inset-*)` which override fixed spacing values. Page indicator dots positioned 32px from bottom (inside safe area).

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 24px | 300 (light) | 1.2 |
| Display | 32px | 200 (thin) | 1.1 |

**Note on weights:** This meditation app uses lighter weights (200, 300) for headings/display to achieve the calm, airy aesthetic. Body/label use regular (400) for legibility. Only 2 weight values used per rendered screen: Display (200) + Body (400) on landing; Label (400) only on placeholders.

**Phase 1 usage:**
- Display (32px/200): App name "mindfulONE" on landing screen
- Body (16px/400): Placeholder text on breathing and meditation screens
- Label (14px/400): Page indicator context (if needed), screen labels

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #000000 | Background of all screens, status bar blend |
| Secondary (30%) | #1A1A1A | Not used in Phase 1 (reserved for future settings panels, cards) |
| Accent (10%) | #FFFFFF | Active page dot, app name text, breathing circle placeholder |
| Muted | #666666 | Inactive page dots, placeholder body text |

Accent reserved for:
- Active page indicator dot
- App name "mindfulONE" on landing screen
- Static white circle placeholder on breathing screen
- Primary interactive elements (future phases)

**No destructive color needed in Phase 1** — there are no destructive actions.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | None in Phase 1 (no interactive actions beyond swipe) |
| Landing heading | "mindfulONE" |
| Landing subtext | None (logo placeholder + name only, minimal) |
| Breathing placeholder | "Breathe" (single word, centered) |
| Meditation placeholder | "Meditate" (single word, centered) |
| Empty state heading | Not applicable (no data-dependent views) |
| Empty state body | Not applicable |
| Error state | Not applicable (static shell, no network-dependent UI) |
| Destructive confirmation | Not applicable (no destructive actions) |
| Offline fallback | Not needed — entire app is offline-first, no fallback state |

**Tone:** Single words. Calm. No exclamation marks. No instructions. The UI should feel like a resting place, not a task manager.

## Layout Contract

| Property | Value |
|----------|-------|
| Viewport | `100dvh` x `100vw` (dynamic viewport height for iOS) |
| Orientation | Portrait locked via manifest |
| Safe areas | `padding: env(safe-area-inset-top) env(safe-area-inset-right) env(safe-area-inset-bottom) env(safe-area-inset-left)` applied to outermost container |
| Background | `#000000` on `<html>` and `<body>` to prevent white flash |
| Overflow | Hidden on body (swipe container handles scroll) |
| Panel layout | Each panel is exactly `100vw` x `100dvh`, flex row |
| Dot position | Centered horizontally, 32px from bottom edge (inside safe area inset) |
| Content alignment | All screen content vertically and horizontally centered |

---

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Swipe left/right | Navigates between panels with momentum snap |
| Snap threshold | 30% of viewport width or velocity > 0.5 |
| Animation | CSS `scroll-snap-type: x mandatory` or equivalent JS with 300ms ease-out |
| Dot update | Immediate on snap, not during drag |
| Overscroll | Prevented — no bounce past first/last panel |
| Tap | No tap targets in Phase 1 (all interaction is swipe) |

## Visual Details

### Breathing Circle Placeholder
- Shape: Perfect circle
- Color: #FFFFFF
- Size: 120px diameter (static, not animated in Phase 1)
- Position: Centered vertically and horizontally within panel
- Border: None
- Shadow: None (future phases may add glow)

### Page Indicator Dots
- Shape: Perfect circles
- Size: 8px diameter each
- Gap: 8px between dots
- Active color: #FFFFFF
- Inactive color: #666666
- Transition: opacity 200ms ease on color change
- Count: 3 dots (Landing, Breathing, Meditation)

### Logo Placeholder Slot
- Size: 64px x 64px reserved area
- Position: Centered horizontally, 48px above app name
- Content: Empty `<div>` with dimensions set, no visual (user provides asset later)
- Fallback: If no image loaded, slot is invisible (no broken image icon)

## Accessibility Notes

| Concern | Approach |
|---------|----------|
| Screen reader | Each panel has `aria-label` ("Landing", "Breathing", "Meditation") |
| Page dots | `role="tablist"` with `aria-label="Navigation"`, each dot is `role="tab"` |
| Reduced motion | Respect `prefers-reduced-motion: reduce` — disable swipe animation, use instant snap |
| Color contrast | White (#FFFFFF) on black (#000000) = 21:1 ratio (AAA) |
| Touch target | Dots are 8px visual but 44px tap target via padding |

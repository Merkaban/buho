<objective>
Build the meditation player vertical slice: from a tap on a library row, the user lands on a player view that plays the selected meditation, shows elapsed/total time, supports play/pause toggling, releases wake lock cleanly on pause/stop/end, and returns to the library on natural end or back-tap. Implements MEDT-04 (tap to play), MEDT-05 (player UI + controls), MEDT-06 (wake lock during playback), and reinforces MEDT-08 (aesthetic).

Per D-13 (minimal text-only player — large play/pause, title, elapsed/total, no seek bar, no skip), D-14 (tap toggle + back/stop affordance), D-15 (auto-stop on natural end), D-16 (wake lock acquired on play, released on pause/stop/end), D-17 (Howler reuse — one Howl instance, iOS unlock pattern from Phase 3), D-18 (independent of breathing audio — no shared state, no modifications to `useBreathingAudio`/`useWakeLock`), and UI-SPEC §"Meditation Player" lines 186–213.

Purpose: Without this slice the user can build a library but never hear it. Shipping it as its own plan keeps Howler's lifecycle (lazy-construct-on-play, unload-on-cleanup, revoke-after-unload — RESEARCH.md Pitfall 1) and the wake-lock dance (Pitfall 5) in a single reviewable diff.
Output: A `useMeditationPlayer` hook (D-16 wake-lock + D-17 Howler) + `MeditationPlayer` component (D-13 layout + D-14 controls) + two test files; combined, they make `<MeditationPlayer meditation={record} onBack={...} />` a self-contained playing widget. D-18 invariant: no edits to existing breathing-audio or wake-lock modules.
</objective>
